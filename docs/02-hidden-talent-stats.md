# 隠しステータス（才能ステータス）仕様

## 概要
プレイヤーが誕生時に、5つの「才能ステータス」がランダムで決定される。これらは**プレイヤーに最後まで数値では開示されない**隠しパラメーターで、人生のあらゆる場面に影響する。

**哲学**：人生は「遺伝・才能（50%）+ 環境・努力（50%）」で決まる。選択と努力も大事だが、生まれ持った才能も同等に重要。

---

## 1. 5つの才能ステータス

### 1-1. 学力（Academic Ability）
**定義**：読み書き計算、理論的思考、記憶力の素質  
**影響範囲**：
- 進学試験の合否判定
- 各教科の通知表
- 職業選択時の難易度（エンジニア、医者など）
- 高度な職業への昇進確率

**初期化**：0～100、正規分布（μ=80, σ=20）

---

### 1-2. コミュ力（Communication Ability）
**定義**：人間関係構築、共感力、説得力、社交スキルの素質  
**影響範囲**：
- 人間関係・結婚イベントの発生確率
- 恋愛相手が見つかりやすさ
- 職場での昇進確率
- 営業職など対人スキル必須職への適性
- 友達の数や信頼度

**初期化**：0～100、正規分布（μ=80, σ=20）

---

### 1-3. 芸術センス（Artistic Sense）
**定義**：創造性、美的感覚、表現力の素質  
**影響範囲**：
- 図画工作、音楽の成績
- アーティスト、デザイナー職への適性
- 芸術系の職業選択可能性
- 創造的な解決策を思いつきやすさ
- 娯楽関連職の給料・昇進

**初期化**：0～100、正規分布（μ=80, σ=20）

---

### 1-4. 運動能力（Athletic Ability）
**定義**：体の動き、反応速度、持久力、身体能力の素質  
**影響範囲**：
- 体育の成績
- スポーツ職（プロスポーツ選手など）への適性
- テレビゲーム選択時のゲーム成績
- 健康を保つしやすさ
- ストレス軽減効果

**初期化**：0～100、正規分布（μ=80, σ=20）

---

### 1-5. 健康値（Health Constitution）
**定義**：免疫力、病気のしやすさ、寿命の素質  
**影響範囲**：
- 病気・事故イベントの発生確率
- 病気からの回復速度
- 医療費の金額
- 60代以降の重篤病気リスク
- 最終的な死亡年齢（目安）

**初期化**：0～100、正規分布（μ=80, σ=20）

---

## 2. ランダム分布の設定

### 2-1. 正規分布パラメーター

```
各才能ステータス = 正規分布(μ=80, σ=20)
範囲：0～100（範囲外は自動的にクリップ）
```

**分布の意味**：
- μ=80：平均が80（やや高め。「普通」を少し上回る設定）
- σ=20：標準偏差20（68%が60～100、95%が40～100に分布）

**具体例**：
| スコア範囲 | 確率 | 意味 |
|-----------|------|------|
| 0～40 | 2.3% | 才能が極めて低い（稀） |
| 40～60 | 13.6% | 才能が低い |
| 60～80 | 34.1% | やや低め～平均 |
| 80～100 | 50% | 平均以上 |

---

### 2-2. 初期化タイミング

**ゲーム開始時**に一度だけ、5つの才能が決定される。

```
function initializeTalents() {
  talents = {
    academic: randomNormal(80, 20),      // 学力
    communication: randomNormal(80, 20),  // コミュ力
    artistic: randomNormal(80, 20),       // 芸術センス
    athletic: randomNormal(80, 20),       // 運動能力
    health: randomNormal(80, 20)          // 健康値
  };
  // 全て0～100の範囲にクリップ
  talents = Object.entries(talents).reduce((acc, [k, v]) => {
    acc[k] = Math.max(0, Math.min(100, v));
    return acc;
  }, {});
  
  return talents;
}
```

## 3. 才能ステータスの影響メカニズム

### 3-1. ランダムイベント時の成否判定

イベント発生時、才能ステータスが結果に影響する。

**例：進学試験イベント（難関高校受験）**

```
成功確率 = (学力 / 100) × 難度調整係数 + ランダムノイズ
難度調整係数：難関高 = 0.8, 普通高 = 1.2
ノイズ：±20%

例：
学力 = 60 の場合
難関高合格確率 = (60/100) × 0.8 + ノイズ = 48% ± 20%
            = 28%～68%

学力 = 90 の場合
難関高合格確率 = (90/100) × 0.8 + ノイズ = 72% ± 20%
            = 52%～92%
```

---

### 3-2. パラメーター上昇への影響

3歳・6歳の選択による傾向値が、才能ステータスに掛け合わされる。

```
毎年のパラメーター増加 = 才能ステータス × 0.3 + 選択傾向ボーナス + ランダム変動

例：
学力才能 = 70、計算選択（+5傾向）
毎年学力増加 = 70 × 0.3 + 5 + ランダム(-2～+2)
           = 21 + 5 + ランダム
           = 26～28/年
```

---

### 3-3. 職業選択時の難易度変動

職業選択時、才能ステータスが選択肢の難易度を変える。

```
職業難易度 = 基本難度 × (関連才能 / 80)

例：エンジニア職（基本難度100、関連才能=学力）
学力 = 50 の場合：難度 = 100 × (50/80) = 62.5（入りやすい）
学力 = 100 の場合：難度 = 100 × (100/80) = 125（難しい・選びにくい）

→ 才能が低いほど、その職業に「入りやすい」
→ 才能が高いほど、その職業が「選択肢として優先される」
```

## 4. プレイヤーへの情報開示

### 4-1. ゲーム中の情報

**数値は一切表示しない**。代わりに以下の形で間接的に伝える：

#### 通知表（小学1年～高校3年）
- 小学：「◎〇△」 （教科別）
- 中高：「1～5段階」（教科別）
→ これが隠した学力の分布を示す

#### ヒントメッセージ
- 「絵が上手だと先生に褒められた」（芸術センスが高い）
- 「クラスメイトが『一緒に遊ぼう』と声をかけてくる」（コミュ力が高い）
- 「すぐに風邪をひく」（健康値が低い）

#### ランダムイベントの結果
- 試験に受かったか落ちたか
- 恋愛イベントが起きたか起きなかったか
→ 結果から、プレイヤーが自分の才能を推測できる

---

### 4-2. エンディング画面での開示

**ゲーム終了時**、初めて5つの才能ステータスが数値で表示される。

```

努力でカバーできた部分も多かったようです。
```

## 5. デザイン上の工夫

### 5-1. 「努力が報われない」というリアリティ

3歳で「絵をかく」を選んで、毎年頑張ったのに成績が伸びない場合：
- **隠し才能「芸術センス」が20だった**
- 毎年 20 × 0.3 + 5 = 11/年程度の増加
- 18年で198なので、大きく伸びにくい

逆に、隠し才能「芸術センス」が95だった場合：
- 毎年 95 × 0.3 + 5 = 33.5/年の増加
- 同じ「頑張り」でも、成長速度が全く違う

→ **「頑張り（3歳・6歳選択）」も「才能（ランダム）」も両方大事**というメッセージ

### 5-2. 環境による補正イベント

東京生まれの場合、コミュ力上昇イベントが多く発生する（初期値ボーナスではなく、イベント発生率が高い）。

```
例：東京生まれで25歳のプレイヤー
【イベント】
「大都市の刺激的な環境で、新しい友達ができた」
→ コミュ力 +5（東京ボーナス）

地方生まれなら、このイベントの発生確率が低い
```

## 6. 実装時の注意点

- **正規分布の実装**：JavaScript `randomNormal()` 関数で実装
  - Box-Muller変換などで正規乱数生成
  
- **シード値の保存**：ゲーム中断後の再開でも同じ才能値を使用
  - ゲーム開始時にシード値をローカルストレージに保存

- **隠蔽性**：プレイヤーが絶対に隠し才能の数値を知られないようにする
  - DevToolsでも見えない仕組み（前のターンで消去、暗号化など検討）

- **統計的妥当性**：正規分布（μ=80, σ=20）が5つ独立に決定
  - 相関させない（学力が高いからコミュ力も高い、など）
  - ただし環境（都道府県）による補正は同一方向
