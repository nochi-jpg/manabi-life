# 🎮 まなびライフ - 完全仕様書

## 概要
小学5～6年生向けキャリア教育テキストベースライフシミュレーションゲーム。日本の統計データをベースに、「遺伝・才能50% + 環境・努力50%」で人生を決定する。

---

## 🎯 基本仕様

| 項目 | 仕様 |
|------|------|
| **タイトル** | まなびライフ |
| **ジャンル** | テキストベースライフシミュレーション |
| **対象年齢** | 小学5～6年生 |
| **プレイ時間** | 1ゲーム等速で12〜15分（docs/12 で決定） |
| **プラットフォーム** | ブラウザ（HTML5） |
| **学習目標** | キャリア教育（進路・職業・人生設計） |
| **ゲーム人生** | 年齢6～80歳（74年間） |
| **難易度** | イージー・ノーマル・ハード |

---

## 📊 ゲーム進行フロー

```
【スタート画面】
難易度選択 → 誕生都道府県ランダム決定 → 才能ステータス5つ決定

【年齢6歳～15歳】学生期前期
・3歳選択「好きなこと」（外遊び、読書、絵画、計算、テレビゲーム）
・6歳で選択変更/確定
・毎年イベント発生
・部活開始（中学）
・交通事故、病気など

【年齢16～22歳】学生期後期
・通知表開始（◎〇△ → 1～5段階）
・進路選択イベント（5択 + More）
・合格率パーセント表示
・16歳からアルバイト開始
・恋愛イベント開始

【年齢23～40歳】仕事・結婚期
・就職選択、5年ごと転職イベント
・給料・昇給・ボーナス管理
・結婚・出産イベント
・住宅ローン
・子どもの教育費

【年齢41～60歳】キャリア充実期
・昇進・管理職
・親の介護イベント
・加齢性疾患

【年齢61～80歳】人生終盤
・定年・退職金・年金開始
・孫との関係
・重篤な病気
・死亡

【エンディング】
0～100点スコア表示
5段階エンディング分岐
隠しステータス初開示
```

## 🧬 隠しステータスシステム（プレイヤー非表示）

### 5つの才能（誕生時にランダム決定）
正規分布（平均80、標準偏差20）、0～100、プレイヤーには数値非表示

| 才能 | 影響範囲 |
|------|---------|
| **学力** | 進学試験、通知表、職業選択難易度 |
| **コミュ力** | 恋愛、結婚、職場昇進、営業職適性 |
| **芸術センス** | 図画工作、音楽、デザイナー適性 |
| **運動能力** | 体育成績、スポーツ適性、健康維持 |
| **健康値** | 病気リスク、寿命、医療費 |

**ヒント表示例**：「絵が上手だと先生に褒められた」「クラスメイトが一緒に遊ぼうと声をかけてくる」

## 🎓 進学システム

### 進路指導者
- 幼児期（～5歳）：親のみ
- 初等・中等（6～14歳）：親 + 先生
- 高等・大学（15～）：親 + 先生

### 進路選択
- **5択 + "もっと見る"ボタン**で追加候補表示
- **合格率をパーセント表示**
- 進学できない場合：留年 or 就職を選択
- 奨学金イベント（15～18歳）

### 学校データ（リアルな情報）
- 全国の学校を地名+学部+偏差値で生成（実名使わず）
- 東京：1200~300（多）
- 地方県：150~50（少）
- 通信制高校、夜学、専門学校、インターナショナルスクールなど

---

## 💼 就職システム

### 就職選択
- 5択 + "もっと見る"で追加候補表示
- **採用試験合格率をパーセント表示**
- 非正規職の可能性（選択 or 強制）
- 業界：IT、製造、営業、医療など多様

### 職業パラメーター（毎月更新）
- 給料（月額、年額、ボーナス）
- 昇給（毎年3～5%）
- 残業時間（月20時間程度）
- ストレスレベル（low/medium/high）
- 肉体的つらさ（low/medium/high/very_high）
- ワークライフバランス
- 転職5年ごと

### 給料・生活費管理
```
給料500万の場合：
- 健康保険、厚生年金、所得税天引き
- 手取り：約27万/月
- 家賃：-8万
- 食費：-3万
- 光熱費、交通費など：-1万
- 交際費、娯楽：-3万
- 貯金：約12万/月
```

## 👨‍👩‍👧 家庭経済システム

### 家庭の裕福さ（隠しステータス）
- very_rich（1500万以上）：進学全額サポート
- rich（1000～1500万）：進学可能、奨学金不要
- middle（500～1000万）：進学可、奨学金検討の余地
- poor（250～500万）：進学困難、奨学金必須
- very_poor（250万以下）：進学困難、生活保護検討

### 奨学金イベント（15～18歳）
- 貸与型：月3万返済、20年間
- 給付型：返済不要（学力要件あり、落ちた場合選べない）
- 親にサポートしてもらう
- アルバイト + 進学

## 🎯 3歳・6歳選択システム

### 選択肢
1. **外で遊ぶ** → 運動能力+5/年、コミュ力+3/年
2. **本を読む** → 学力+4/年、芸術センス+3/年
3. **絵をかく** → 芸術センス+5/年、学力+2/年
4. **計算する** → 学力+5/年、運動能力+1/年
5. **テレビゲーム** → コミュ力+3/年、学力+2/年、運動能力+2/年
6. **何もしない** → ランダム上昇、コミュ力やや高め

### パラメーター上昇ロジック
```
毎年増加 = 隠し才能 × 0.3 + 選択傾向ボーナス + ランダム変動

同じ選択（3歳→6歳）：傾向ボーナス +20%
選択変更：新傾向+20%、前傾向-50%
```

## 🎭 ランダムイベントシステム

### イベント発生メカニズム
- 基本確率 × (関連才能/80) + 年代補正 ± ランダム
- 年齢別カテゴリ（進学、恋愛、病気、親の問題など）

### 主要イベント
| 年代 | イベント |
|------|---------|
| 6～15歳 | 進学、成績、いじめ、親の転職、病気 |
| 16～22歳 | 高校進学、大学受験、恋愛、アルバイト |
| 23～40歳 | 就職、昇進、結婚、出産、住宅購入 |
| 41～60歳 | 親の介護、加齢性疾患、子育て費用 |
| 61～80歳 | 定年、退職金、年金、孫、重篤病 |

### リアルなリスクイベント
- **交通事故**：年代・地域別確率、軽度/重度/死亡
- **親の離婚**：家庭ゲージ-30、親の経済-15%
- **親の失業**：家庭経済-30%
- **親の介護**：月費用+5～15万、給料-30%（同居時）
- **親の死亡**：喪失感で進行遅延、遺産or借金相続

## 🏫 教育環境システム

### アルバイト（16～22歳）
- コンビニ：時給1200、週20時間、ストレス+2、学力-10/年
- ファストフード：時給1150、週25時間、ストレス+3、学力-15/年
- 家庭教師：時給2500、週10時間、ストレス+1、学力+5/年
- 配達：時給1400、週30時間、ストレス+2、学力-20/年
- 研究被験者：時給1000、週5時間、ストレスなし

### 部活動（中高）
- **硬式野球**：運動能力+10、時間的拘束最大、燃え尽きリスク
- **美術部**：芸術センス+10、時間的自由、学力支障なし
- **吹奏楽**：芸術センス+10、コミュ力+5
- **受験勉強（部活なし）**：学力+15、友達減少、大学合格率+30%

### 大学サークル（18～22歳）
- **テニスサークル**：コミュ力+5、出会い最高、月3000円
- **飲み会サークル**：コミュ力+10、学力-20、単位落とすリスク
- **ボランティア**：コミュ力+5、ストレス-5、就職面接で高評価
- **研究サークル**：学力+10、出会い少ない、大学院に有利

## 📍 統計データ反映

### 都道府県別リアリティ
- **東京**：学校1200+、企業45000+、進学容易
- **大阪**：学校400+、企業15000+、就職容易
- **地方県**：学校150+、企業2000+、上京圧力強い

### 進学・就職難易度補正
```
都道府県難易度係数 = 1 - (都道府県進学率 / 全国平均)
最終難度 = 基本難度 × 都道府県係数
```

### 地域別イベント発生率
- **東京**：コミュ力イベント多、恋愛機会多
- **地方**：上京イベント発生しやすい

## 💰 経済・社会保障システム

### 健康保険
- 未成年：親の保険
- 学生：学生健康保険（月2000）
- 会社員：厚生健康保険（給料天引き5000）
- 自営業：国民健康保険（月8000自己負担）

### 年金制度
- 厚生年金：給料から月6000自動天引き
- 国民年金：自営業月16000自己負担
- **65歳から受け取り開始**
- 平均月額：18万（生活費13万では不足 → 貯金取り崩し）

### 退職金
- 企業20年勤続：300～500万
- フリーランス：なし
- 転職多い：大幅減少

### 借金管理
- 奨学金：月1.5～3万返済（20年）
- 住宅ローン：月6～7万（35年）
- 車ローン：月6000～1万（5年）
- クレジット・消費者金融：金利高い

## 🏆 エンディングシステム

### スコア計算（80歳時）
```
学歴ゲージ：最大25点（0～100を25に変換）
仕事満足度：最大25点
家庭ゲージ：最大25点
資産：最大25点（3000万以上で25点）
```

### エンディング分岐
| スコア | エンディング | 説明 |
|-------|----------|------|
| 80～100 | 🏆 幸福な人生 | 充実した人生。孫に囲まれて |

| 40～59 | 📖 波乱万丈 | 良い悪いが混ざった人生 |
| 20～39 | ❓ 試行錯誤 | 迷いながらも歩んだ人生 |
| 0～19 | ⚠️ 困難な人生 | 環境とのギャップが大きい |
