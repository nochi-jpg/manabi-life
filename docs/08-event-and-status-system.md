# イベント＆イベントステータスシステム仕様

## 概要
「膨大なイベント」「膨大なイベントステータス」「膨大な分岐条件」により、プレイするたびに異なる人生体験をもたらす。これが**リアルな人生シミュレーション**の肝。

---

## 1. ゲーム内イベント発生頻度

### 基本ルール
- **年4回イベント発生**（春・夏・秋・冬、各季節に1回）
- 74年間のゲーム内で **74年 × 4 = 約296イベント発生**
- プレイ時間10分で296イベント ≈ 2秒/イベント平均

---

## 2. イベントの2つの形式

### 形式A：テキストフロー（文字が流れるだけ）
選択肢なし。ナレーション的に流れる。

**例：**
```
【2032年 4月】
🎨 「図工の時間に先生に褒められた」
「あなたの絵が上手だね」と言われました。

【効果】
なし（単なる情報提示）
```

### 形式B：選択肢イベント（ポップアップで確認）
プレイヤーが選択肢から決定を選ぶ。ポップアップで表示。

**例：**
```
【2034年 3月】
📋 「通知表が配られました」
（画面に通知表が表示）

「来年、何を重点的に頑張りますか？」

【選択肢】
① 得意な教科をさらに伸ばす
  → その教科 +10
  
② 苦手な教科を克服する
  → その教科 +5（但し時間がかかる）
  
③ 部活に力を入れる
  → コミュ力 +5、学力 -3
```

## 3. 選択肢イベントの2分類

### A. 必須イベント（毎年必ず発生）

年齢・学年ごとに**必ず発生する**イベント。スキップできない。

**例：**

| 時期 | イベント | 発生条件 |
|------|---------|---------|
| **3月毎年** | 📋 通知表配布 | 小1～高3（学生期） |
| **小4春** | 「中学受験するか」 | 東京都など進学率高い地域 |
| **小6春** | 「進学先決定」 | 全員必須 |
| **中3春** | 「進路選択（高校）」 | 全員必須 |
| **高2秋** | 「大学受験or就職」 | 全員必須 |
| **高3春** | 「進学先最終決定」 | 進学選択者 |
| **18歳前後** | 「アルバイト始めるか」 | 任意だが勧誘イベント |
| **20代** | 「恋人との結婚」 | 恋愛イベント後 |
| **30代** | 「子ども計画」 | 結婚後 |
| **60代** | 「定年迎える」 | 全員（会社員の場合） |

### B. ランダムイベント（確率で発生）

毎年、確率でランダムに発生。内容は膨大。

**例：**

```
【恋愛系】
・告白される「付き合いますか？」
・不倫誘い「浮気しますか？」
・別れ話「別れますか？」
・婚活パーティに誘われる

【健康系】
・風邪をひく「病院に行きますか？」
・事故に遭う「入院しますか？」
・がん検診で肺がん診断「治療法を選ぶ」
・親が病気「介護しますか？」

【社会問題系】
・タバコをすすめられる「吸いますか？」
・麻薬誘い「使いますか？」
・補導される「反省しますか？」
・逮捕される「前科つきますか？」

【経済系】
・宝くじが当たる「どう使いますか？」
・詐欺にあう「被害者になりますか？」
・投資話を持ちかけられる「乗りますか？」

【環境系】
・転勤辞令「引っ越しますか？」
・転職スカウト「転職しますか？」
・起業を勧められる「起業しますか？」
```

## 4. パラメーター補正システム

選択により、**その後の人生に永続的な影響**が出る。

### 例1：喫煙選択
```
選択：「タバコを吸う」

【永続的な補正】
毎年：
- 健康値：-5
- 肺がんリスク：+3%（毎年累積）
- 医療費：+5万/月（30代以降）
- モテ度：-10（現代）
- ストレス：-3（喫煙でのリフレッシュ）

40代以降：
- 肺がん罹患確率大幅UP
- 医療費月20万かかることも
```

### 例2：免許取得
```
選択：「自動車運転免許を取得」

【初期コスト】
お金：-30万（教習所費用）

【永続的な効果】
毎月：
- 交通費：-2万（移動効率UP）
- 幸福度：+5
- コミュ力：+2（移動範囲拡大で出会い増加）

【新しいイベントが発生可能】
- ドライブデート（出会いUP）
- 交通事故（確率UP）
- 返納イベント（60代）
```

### 例3：大学院進学
```
選択：「大学院（修士課程）に進学」

【初期コスト】
お金：-200万（学費2年分）
時間：2年間給料なし

【永続的な効果】
生涯給料：+20%（平均）
職業選択肢：研究職、大学教員が可能に
結婚可能性：+10%（学歴により）

【新しいイベント】
- 博士課程進学勧誘
- 研究費獲得
- 論文投稿イベント
```

## 5. イベントステータスシステム（新概念：極めて重要）

**「イベントステータス」とは：**
プレイヤーが特定の選択をした結果、付与される**タグ・ラベル**。
これらのステータスの有無により、**他のイベント発生が大きく変わる**。

## 7. イベントステータスによる分岐条件

### 例1：逮捕歴
```
【逮捕歴あり → 以下のイベント/選択肢は発生不可】
- 公務員職への就職
- 警察官
- 教員
- 医師（医学部進学選択肢消滅）
- 弁護士
- 金融機関職員
- 大手企業採用試験

【逮捕歴あり → パラメーター低下】
- 結婚可能性：-50%
- 給料：-20%（給料の低い企業しか雇わない）
- 人間関係：-30%

【追加イベント発生】
- 親からの責めイベント
- 職場での差別イベント
- 結婚相手の親からの反対イベント
```

### 例2：車保有
```
【車保有あり → 新しいイベント発生】
- ドライブデート（出会いイベント増加）
- 交通事故リスク（毎年5%）
- ガソリン代：毎月3万
- 保険料：毎月1万
- 自動車税：年1万

【車保有あり → イベント分岐変更】
- 地方への転勤を受け入れやすくなる
  → 給料UP + 出会い増加
- 週末のレジャーイベント増加
  → コミュ力 +5, ストレス -3
```

### 例3：博士号取得
```
【博士号取得 → 新しい職業選択肢】
- 大学教授
- 研究員
- シンクタンク研究員
- 国際機関職員

【博士号取得 → 給料UP】
- 初任給：+30%
- 生涯給料：+50%

【博士号取得 → 結婚パラメーター】
- 結婚可能性：+20%（学歴による）
- 相手の社会的地位：高まる傾向

【追加イベント】
- 研究費獲得イベント
- 論文の採用/不採用イベント
- 学会発表イベント
```

### 例4：子ども2人以上
```
【子ども2人以上 → 生活費変動】
- 養育費：子ども1人+10万/月
- 教育費：子ども1人+5万/月（中高）

【子ども2人以上 → 転職制限】
- 転勤を受け入れにくくなる
  → 給料UP機会喪失

【子ども2人以上 → 休日活動】
- 家族イベント増加
  → コミュ力UP、健康UP
  → しかし自由時間-50%
```

## 8. 所持金ステータスによる選択肢分岐

### 例：投資イベント
```
【お金がない場合（所持金100万以下）】
「投資話を持ちかけられた」
→ 「小額投資する（10万）」のみ選択肢

【お金がある場合（所持金500万以上）】
→ 「小額（10万）」「中額（100万）」「大額（500万）」の3選択肢

大額投資選択：
成功時：500万 → 1500万
失敗時：500万 → 0円（全喪失）
```

### 例：ローン購入
```
【所持金200万未満】
→ 住宅購入ローン申請
→ 審査通過率低い（20%）

【所持金500万以上】
→ 住宅購入ローン申請
→ 審査通過率高い（80%）
```

## 9. イベント発生の複合条件

複数のステータスが組み合わさることで、**特定の人だけに起こるイベント**が発生する。

### 例1：医学部進学イベント
```
発生条件：
- 学力ステータス：85以上
- 親の経済状況：middle以上
- 親が医師or医療関係（ランダム要素）

結果：
医学部進学が強く勧められる
→ 親からの強い期待イベント
→ 医学部受験イベント（合格率50%）
```

### 例2：玉の輿イベント
```
発生条件：
- 性別：女性（or男性、稀）
- 顔面偏差値：隠しステータスで高い
- コミュ力ステータス：70以上
- 年齢：20～35歳
- 独身ステータス
- 相手の給料：1000万以上

結果：
「玉の輿イベント」発生確率UP
婚活パーティで富豪と出会う確率UP
```

### 例3：AI時代のキャリア
```
発生条件：
年齢：2045年以降の生まれ
英検1級保有
IT関連資格保有
大学卒

結果：
「AI時代のキャリア再教育」イベント発生
AIと共存する職業選択肢が増加
```

## 10. イベント総数と分岐数（目標）

### 必須イベント数
- 年代別 × 学校段階別 = **約50～100個**

### ランダムイベント数
- カテゴリ × バリエーション = **約300～500個**

### 総イベント数
- **400～600個のイベント**

### 分岐条件
- イベントステータス × 所持金 × 才能値 × 地域 = **数千～数万の分岐**

**結果：** プレイするたびに異なる人生体験が可能

## 11. 実装上の注意点

### A. イベントの一意性
- 同じイベント（例：喫煙勧誘）が何度も出現しない
- 一度選択したイベントは、特定の条件下で再発生することはあるが、基本は1回のみ

### B. イベント順序のランダム性
- 各年の4つのイベント発生順序はランダム
- プレイするたびに順序が変わる

### C. パラメーター補正の段階的影響
- 喫煙→即座に健康値低下ではなく、5年後に肺がんリスク顕在化
- 現実的なタイムラグを考慮

### D. イベントステータスの取り消し不可
- 一度「逮捕歴あり」になると、ゲーム中に消えない
- 人生の現実性を反映

---

## 12. ゲームの深さと多様性

このイベント＆ステータスシステムにより：

1. **初回プレイ** → 「必須イベント」で基本的なストーリーを経験
2. **2回目プレイ** → 「ランダムイベント」で全く異なるストーリーに
3. **3回目以降** → イベントステータスの組み合わせで、無限のバリエーション

**結果：** 小学5～6年生が何度も遊ぶモチベーションが生まれる
