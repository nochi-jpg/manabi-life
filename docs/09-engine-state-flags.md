# 09 エンジン・状態・フラグ管理仕様（v1）

この文書は「まなびライフ」の**ゲームエンジンの心臓部**。イベント・学校・職業・部活のデータ（`data/*.json`）はすべてここで定義した書式と不変条件に従う。
目的は2つ。**①パラメーターが相互に作用してリアルになること、②「子がいないのに孫が生まれる」のような矛盾が構造的に起きないこと。**

---

## 0. 既存仕様（01〜08）からの修正点

| # | 既存の記述 | 修正 | 理由 |
|---|---|---|---|
| 1 | 才能は正規分布 μ=80, σ=20 | **μ=50, σ=15（1〜99でクリップ）** | 平均80だと「普通の子」が上位寄りになり、通知表が◎だらけになる。50＝同学年の真ん中、という偏差値的な感覚に揃える |
| 2 | 職業難易度＝基本難度×(才能/80)（才能が高いほど難しくなる式） | **合格率＝ロジスティック関数（§6）** | 旧式は向きが逆で、才能が高いほど入りにくくなるバグ |
| 3 | 人生は6〜80歳固定 | **0歳誕生〜死亡まで（最大105歳）。0〜5歳は年2枠に圧縮、80歳以降も年2枠に圧縮** | 3歳の選択と矛盾していた。寿命も健康で変わる方がリアル |
| 4 | ゲージ「学歴・仕事満足度・家庭・健康」 | **UI案に合わせて §2 の表示ステータスに統一** | UI案（本人ステータス／職業ステータス）と仕様書がずれていた |
| 5 | 年齢は誕生日で加算 | **「学年年齢」で管理：毎年4月（春枠）に+1** | 学年・受験・就職の判定がずれないようにする |
| 6 | 麻薬・不倫イベント案 | **収録しない**（喫煙・飲酒・万引き誘い・補導・逮捕は収録） | 対象が小5〜6。80億分の1は15歳以上向け。リアルさは保ちつつ線を引く |

## 1. 時間の流れ（四半期エンジン）

### 1-1. 1年＝4枠
| 枠 | 月 | 呼び名 | 主な必須イベント |
|---|---|---|---|
| Q1 | 4〜6月 | 🌸春 | 入学・進級・入社・部活選択・**年齢+1** |
| Q2 | 7〜9月 | 🌻夏 | 夏休み・大会・インターン・ボーナス |
| Q3 | 10〜12月 | 🍁秋 | 志望校決定・文理選択・就職試験・健康診断 |
| Q4 | 1〜3月 | ⛄冬 | 受験本番・**通知表と重点方針**・卒業 |

### 1-2. 枠の埋め方（毎枠この順で処理）
1. **予約イベント**（過去の選択で「◯年後に起こる」と予約されたもの。例：がん検診→結果）
2. **必須イベント**（その年齢・時期・状態なら必ず起こる）
3. **ランダム選択肢イベント**（条件を満たす候補から重み付き抽選。**1枠に選択肢イベントは最大1つ**）
4. 何も起きなければ **流れるだけイベント**（ヒント・日常・家族の出来事）を1〜2本

### 1-3. ペース配分（1プレイ10分）
- 0〜5歳：年2枠（春・秋）、6〜79歳：年4枠、80歳〜：年2枠
- 選択肢イベントの目安：**生涯で60〜90回**。ランダム選択肢イベントは同一年に最大2回まで
- 等速で流れるだけイベント1本＝約1.5秒、2倍・4倍で短縮。選択肢イベントは自動で一時停止

### 1-4. 毎枠の終わりに行う「状態更新」（§5）
お金の出入り → 健康・ストレスの自然変化 → 継続効果（喫煙など）の適用 → 家族エンティティの加齢 → 不変条件チェック

## 3. 成長のしくみ

### 3-1. 好きなこと（3歳・6歳）＝「向き」
| ID | 選択肢 | 伸びやすい教科・スキル | 相性の良い職種カテゴリ |
|---|---|---|---|
| `like_outdoor` | 🏃外で遊ぶ | 体育, skill.sport | sport, outdoor, physical |
| `like_book` | 📖本を読む | 国語, 社会 | writing, education, law |
| `like_draw` | 🎨絵をかく | 図工/美術, skill.art | creative, design |
| `like_math` | 🔢計算する | 算数/数学, 理科 | engineering, finance, science |
| `like_game` | 🎮テレビゲーム | skill.it, 算数（少） | it, creative |
| `like_none` | 🙂特になし | 全教科少しずつ | なし（どの職でも満足感に±0） |

- 3歳と6歳が同じ → 「好き」が固まる：伸び×1.2、相性ボーナス×1.5
- 違う → 6歳の方を採用、3歳の向きは×0.5で残る
- 好きなことは**才能と無関係**。好き×才能低い＝「好きだけど伸び悩む」、才能高い×好きでない＝「得意だけど興味がない（満足感が低め）」

### 3-2. 教科別学力の初期値
`subj.X = clamp( t_academic + N(0,10) + 好きなこと補正(+5) , 1, 99 )` を6歳時点で生成。
教科：`jpn`国語, `math`算数・数学, `sci`理科, `soc`社会, `eng`英語, `pe`体育（`pe` は `t_sport` を基準に生成）, `art`図工・美術（`t_art` 基準、通知表の小1〜2「生活」は jpn と sci の平均で表示）

### 3-3. 毎年の成長式（Q4の通知表処理で1年分まとめて計算）
```
伸び = 基本伸び(学校段階)
     × 才能係数   (0.5 + t/100)            … 才能半分
     × 環境係数   (重点方針 × 学校の質 × 塾・家庭)  … 環境と努力半分
     × 好き係数   (1.0 / 1.2 / 0.5)
     − ストレス罰 (stress>70 なら −30%)
     + N(0,2)
subj.X = clamp(subj.X + 伸び − 忘却, 1, 99)
```
- 基本伸び：小3 / 中4 / 高5 / 大学・社会人 0（英語と専門分野は方針次第で伸びる）
- 忘却：その教科を使わない社会人は年−1（英語は海外勤務・外資なら0）
- 教科別学力は**同学年の中での位置**を表す。50＝ちょうど真ん中

### 3-4. 重点方針（UI「重点方針：勉強▼」）
**毎年Q4の通知表イベントで選ぶ**（いつでも▼から変更可能だが、変更は次の枠から有効、年度途中の変更は効果×0.5）。
学校段階・社会人で選べる項目が変わる。

| 方針 | 選べる時期 | 1年あたりの効果（目安） |
|---|---|---|
| 📚勉強 | 小〜大学院 | 全教科伸び×1.4、stress+8、social−3 |
| 🎯得意を伸ばす | 小〜大学 | 得意上位2教科×1.7、他×0.9 |
| 🩹苦手をなくす | 小〜高 | 下位2教科×1.7、他×0.9、stress+4 |
| ⚽部活・習い事 | 小〜高 | 所属活動のスキル・体育×1.6、social+5、学力×0.85 |
| 🧑‍🤝‍🧑友達と遊ぶ | 小〜大学 | social+8、happiness+4、学力×0.85 |
| 🎮趣味 | 全期間 | 好きなこと系スキル×1.5、happiness+5、stress−6 |
| 💴バイト | 16歳〜学生 | 収入↑（バイト時間2倍）、学力×0.8、stress+4 |
| 💕恋愛 | 15歳〜 | 恋愛イベント重み×2、social+3 |
| 💼仕事 | 社会人 | 昇進判定+15%、月収査定+、stress+8、health−2、家族満足−3 |
| 🏠家族 | 社会人 | 家族満足+6、子の学力伸び+、昇進判定−10% |
| 🏋️健康 | 全期間 | health+5、運動習慣フラグ獲得判定、stress−3 |

| 💹副業・投資 | 20歳〜 | 副収入/投資イベント重み×2、リスクイベントも×1.5 |

## 4. 誕生時の生成（家族と環境）

0. **生まれた年**：**2010年で固定**（2020年に10歳、2030年に20歳）。世の中の出来事（東日本大震災・コロナ・AIの時代）は `data/events_world.json`、AIによる仕事の置きかわりは `data/ai_impact.json`
1. **都道府県**：人口比で抽選（`data/prefectures.json` の population 比）。神奈川が出やすく鳥取は出にくい、が自然に起きる
2. **性別**：**プレイヤーが最初に選ぶ**（男の子／女の子）。恋愛・結婚・出産の相手判定に使う。性別による職業制限は**設けない**
2-2. **名前**：苗字と名前を別々にランダム表示（`data/names.json`）。それぞれ🔀でシャッフル、「自分で決める」で入力。母の旧姓（`motherMaiden`）もこのとき別の苗字から決めておく。苗字は結婚（ev_r_surname_marry）・離婚（ev_r_surname_divorce）・親の離婚で母についていったとき（母の旧姓へ）に変わる
3. **家庭の裕福さ** `familyWealth`：都道府県の世帯所得係数で補正した分布から抽選 → 世帯年収帯
   | 帯 | 値 | 世帯年収 | 出現率（目安） |
   |---|---|---|---|
   | very_poor | 0〜14 | 〜300万 | 12% |
   | poor | 15〜34 | 300〜500万 | 23% |
   | middle | 35〜64 | 500〜900万 | 40% |
   | rich | 65〜84 | 900〜1500万 | 18% |
   | very_rich | 85〜100 | 1500万〜 | 7% |
4. **親**：父・母エンティティ（年齢＝プレイヤー誕生時に 25〜42 で抽選、職業は裕福さ帯に合う職業から抽選）。ひとり親世帯で生まれる確率 約9%
5. **きょうだい**：0人 30% / 1人 50% / 2人以上 20%。年上か年下かも抽選（年下は「◯年後に生まれる」予約イベントとして生成。**親の年齢が45歳を超える予約は作らない**）
6. **祖父母**：4人分を生成（各55〜75歳）。同居フラグは地方ほど高確率
7. **才能・見た目**：§2-4

## 5. 相互作用ルール（毎枠の状態更新）

```
① お金
   収入（給与手取り＝額面×0.78、バイト、年金、手当、仕送り）
 − 支出（生活費[地域×世帯人数]、家賃 or ローン、学費、保険料、子の養育費、介護費、医療費、車、喫煙費）
   → cash に加算。cash<0 になったら `debt_card` フラグ＋初回だけ ev_f_cash_negative。マイナス分に年15%の利息
② ストレス
   stress += 精神負荷×0.05 + 肉体負荷×0.02 + 借金圧(debt/年収×5) + 介護中(+4) + 受験期(+3)
   stress −= social×0.04 + 趣味/休養方針 + 配偶者関係良好(+2)
③ 健康
   health −= 加齢(40歳〜 年0.5、60〜 年1、75〜 年2)×(1.5 − t_health/100)
   health −= stress>70 で +1.5/枠、喫煙 0.5/枠、多量飲酒 0.4/枠、肉体負荷>70 で 0.5/枠
   health += 運動習慣 0.3/枠、健康方針
④ 人間関係
   social は毎年 2% ずつ 50 に戻ろうとする（何もしないと平凡に近づく）
   転居・転校で −15、ひきこもり状態で毎枠 −2
⑤ 満足感（happiness）
   毎枠、目標値に 20% ずつ近づく：
   目標値 = 50 + (social−50)×0.3 + (health−50)×0.3 − (stress−50)×0.4
          + 仕事満足×0.2 + 家族補正 + お金の余裕補正(cash と月収で −15〜+10)
⑥ 継続効果（modifiers）の適用 … 喫煙・持病・介護などは §7
⑦ 家族エンティティの加齢と自動イベント予約（§8）
⑧ 不変条件チェック（§9）→ 違反はログに出して自動修正せずイベントを無効化
```

### 主な連鎖（このゲームの「リアルさ」の源）
- 貧困 → 塾に行けない・バイト必要 → 学力伸び↓ → 進学先↓ → 生涯年収↓（ただし奨学金・給付型・公立トップ校で逆転可能）
- 長時間労働 → stress↑ → health↓ → うつ・脳卒中リスク↑ → 休職 → 収入↓
- 喫煙 → health↓・がんリスク↑ → 医療費↑ → お金↓
- 人間関係↑ → stress↓・恋愛↑・昇進↑・孤独死リスク↓
- 介護 → stress↑・仕事時間↓（介護離職もありうる）
- 車 → 地方での就職先の選択肢↑・出会い↑・事故リスク↑・維持費↑

## 6. 判定式（合格率・成功率）

### 6-1. 入試・採用の合格率（プレイヤーに「合格率◯%」で表示）
```
自分の偏差値 h = 25 + (関連教科の加重平均) × 0.5        … 教科50→偏差値50
差 d = h − 学校/求人の偏差値 + 補正
合格率 p = 1 / (1 + e^(−d / 3.5))   を 3%〜97% にクリップ
```
| 差 d | 合格率 |
|---|---|
| −10 | 5% |
| −5 | 19% |
| 0 | 50% |
| +5 | 81% |
| +10 | 95% |

補正の例：推薦・内申（通知表平均4.0以上で+2）、部活実績（全国大会+3）、面接（採用時は t_comm と social で ±5）、浪人（+2 / 2浪以降は+1）、逮捕歴（公務員・教員・警察等は応募不可＝選択肢自体を出さない）

### 6-2. 才能を使う成功判定（ランダムイベント内）
```
p = base + (才能 − 50) × w / 100        （3%〜97%）
```
例：告白の成功 `base 0.45, t_comm w0.5, looks w0.3, social w0.2`

## 7. 継続効果（modifiers）

フラグとは別に「毎枠効果を出し続けるもの」を modifier として持つ。フラグが消えると modifier も自動で外れる（**フラグと modifier は1対1で紐づける**）。

| modifier | 紐づくフラグ | 毎枠の効果 | リスク倍率 |
|---|---|---|---|
| `mod_smoking` | `smoker` | health −0.5、cash −1.5、stress −0.5 | 肺がん×4、心臓病×2、脳卒中×1.5 |
| `mod_ex_smoker` | `ex_smoker` | なし | 肺がん×2（禁煙10年で×1.3へ） |
| `mod_heavy_drink` | `heavy_drinker` | health −0.4、cash −1 | 肝臓病×3、うつ×1.5 |
| `mod_exercise` | `exercise_habit` | health +0.3、stress −0.5 | 生活習慣病×0.7 |
| `mod_diabetes` | `dz_diabetes` | health −0.3、医療費 −0.5 | 心臓病×2、脳卒中×2 |
| `mod_hypertension` | `dz_hypertension` | 医療費 −0.3 | 脳卒中×2.5 |
| `mod_depression` | `dz_depression` | stress +2、happiness目標 −10、学力・仕事効率×0.8 | — |
| `mod_caregiving` | `caregiving` | stress +4、仕事時間 −20%、cash −（介護度で変動） | うつ×1.5 |
| `mod_owns_car` | `owns_car` | cash −3（保険・税・燃料） | 交通事故×2 |

| `mod_juku` | `juku` | cash（家計）−3、学力伸び×1.3、stress +1 | — |

## 8. 人物エンティティ（フラグ矛盾を防ぐ仕組み）

**家族や恋人は「フラグ」ではなく「人物データ」として持つ。** 孫・介護・相続などはすべて人物データの存在と状態から判定する。

```js
person = {
  id, role,            // father, mother, sibling, grandparent, partner, spouse, ex_spouse, child, grandchild
  name, gender, age,
  alive: true,
  relation: 0〜100,    // プレイヤーとの関係の良さ
  stage,               // 子ども用：nursery/elem/jhs/hs/univ/work …
  job, income,         // 親・配偶者用
  married: false,      // 子ども用（孫判定に使う）
  careLevel: 0,        // 0=自立, 1〜5=要介護度（親・祖父母・配偶者）
  parentIds: []        // 孫は「どの子の子か」を必ず持つ
}
```

### 人物ごとの自動処理（毎年Q1）
| 対象 | 処理 |
|---|---|
| 全員 | age+1。死亡判定（年齢・性別の死亡率×健康補正） |
| 親・祖父母 | 65歳以上で要介護判定（年1〜6%、80歳以上で急増） |
| 子ども | 学校段階を自動で進める（学費を家計から引く）。18歳で進路（家計と子の学力で自動決定）、22〜35歳で結婚判定、結婚した子は出産判定 |
| 配偶者 | 年収変化、病気、関係値の自然変化 |

### 子ども・孫が生まれる条件（例）
- **子ども**：`spouse` または `partner` が存在し alive、かつ「出産する側」（プレイヤーか相手の女性側）の年齢が 18〜45、かつ「子どもをつくる」を選んでいる（or 予期せぬ妊娠イベント）
- **孫**：`child` が存在し、その child が `married:true` かつ child または child の配偶者の年齢 18〜45。**孫の parentIds には必ずその child の id を入れる**

## 9. 不変条件（invariants）— これが破れるイベントは発生させない

イベントは「条件を満たすときだけ候補になる」ので、条件の書き忘れがバグの原因になる。そこで**イベント側の条件とは別に**、エンジンが毎枠以下をチェックし、違反するイベントは実行しない（開発中はコンソールに警告）。

| # | 不変条件 |
|---|---|
| I-1 | 孫 ⇒ その孫の親である子が存在し、その子が結婚済み |
| I-2 | 子どもが生まれる ⇒ 出産時点で配偶者または恋人が存在（生存） |
| I-3 | `married` ⇔ 生存している `spouse` がちょうど1人。結婚中に別の結婚・婚活イベントは不可 |
| I-4 | `divorced` ⇒ 過去に `married` だった（`ex_spouse` が1人以上）。再婚 ⇒ divorced か widowed |
| I-5 | 死亡した人物のイベント（介護・会話・病気）は起きない。同じ人の死亡は1回だけ |
| I-6 | 親の介護 ⇒ その親が生存かつ careLevel≥1 |
| I-7 | 学校段階は順番どおり：小→中→高（または高専/通信/定時/高認）→大学/短大/専門→大学院。飛び級なし。退学・中退は戻れる |
| I-8 | `grad_master` ⇒ `edu_univ_grad`。`grad_doctor` ⇒ `edu_master_grad`。医師国試 ⇒ 医学部6年卒 |
| I-9 | 就業中の本業は常に1つ。転職・退職 ⇒ 就業中。定年 ⇒ 正社員か公務員で60歳以上 |
| I-10 | 年齢制限：飲酒・喫煙の「解禁後の習慣化」20歳〜（未成年の喫煙は補導判定つき）、普通免許18歳〜、結婚18歳〜、選挙権18歳〜、年金受給60〜75歳 |
| I-11 | 資格フラグは「取得イベント」でのみ付く（例：教員免許＝教職課程修了。医師免許＝医学部卒＋国試合格） |
| I-12 | 逮捕歴 ⇒ 応募不可職（公務員・教員・警察・自衛官・弁護士・医師の新規取得）の選択肢を出さない |
| I-13 | cash がマイナスの間は `debt_card` フラグが付き、0以上に戻ると外れる。家の購入 ⇒ cash≥頭金 かつ ローン審査通過（マイナスなら選択肢を出さない） |
| I-14 | 車の購入 ⇒ `lic_car`。車の事故 ⇒ `owns_car` または運転中フラグ |
| I-15 | 在学中フラグは常に1つ（大学と専門の同時在籍なし。ダブルスクールは「資格の勉強」扱い） |
| I-16 | 「一度きり」イベントは生涯1回（成人式、初めての告白、定年など） |

## 10. データの書式（`data/*.json` 共通）

### 10-1. 条件 `when`（すべて AND。省略した項目は不問）
```json
"when": {
  "age": [16, 22],
  "season": ["Q1", "Q3"],
  "stage": ["hs", "univ"],
  "employment": ["seishain", "civil_servant"],
  "all": ["lic_car"],
  "none": ["arrest", "married"],
  "any": ["owns_car", "lives_rural"],
  "stat": { "health": ["<", 40], "stress": [">=", 70] },
  "talent": { "t_comm": [">=", 60] },
  "money": { "cash": [">=", 100] },
  "person": { "role": "spouse", "alive": true },
  "region": ["A", "B"],
  "gender": "F",
  "once": true,
  "cooldownYears": 5,
  "yearsLeft": 1,
  "yearInStage": 2,
  "var": { "plan": ["univ"] },
  "jobYears": [5, 10, 15, 20, 25, 30, 35],
  "child": { "age": [9, 9] }
}
```
- `yearsLeft`：在籍中の学校の残り年数（1＝最終学年）。4年制でも2年制でも同じイベントで就活・卒業を扱える
- `yearInStage`：在籍何年目か（1始まり）
- `var`：エンジン変数（`plan`進路希望、`target`志望校、`pendingExam`受験予定の国家試験 など。`data/flags.json` の vars）
- `jobYears`：今の職場での勤続年数がこのどれかと一致
- `child`：条件を満たす子どもが1人以上いる

### 10-3-2. 効果の追加命令
| 命令 | 例 | 意味 |
|---|---|---|
| `var` | `{"plan":"univ"}` | エンジン変数を設定 |
| `school` | `{"enter":"$pick"}` / `{"leave":"graduate"}` / `{"leave":"dropout"}` | 入学・卒業・中退（I-7, I-15 をエンジンが確認） |
| `job` | `{"hire":"$pick"}` / `{"quit":"self"}` / `{"quit":"fired"}` / `{"form":"part"}` / `{"retire":true}` | 就職・退職・雇用形態の変更（I-9） |
| `move` | `{"to":"tokyo"}` / `{"to":"home"}` / `{"to":"random"}` | 引っ越し（都道府県が変わる。social−15） |
| `focus` | `"$pick"` | 重点方針の変更 |
| `club` | `{"join":"$pick"}` / `{"quit":true}` | 部活・習い事・サークル |
| `person` | `{"add":"partner"}` / `{"promote":"partner>spouse"}` / `{"end":"spouse>ex_spouse"}` / `{"kill":"father"}` / `{"care":"mother","level":2}` | 人物の追加・関係の変化 |
| `menu` | （選択肢側）`{"source":"schools.highSchool","page":5,"showRate":true}` | データから候補を作り5件ずつ表示。6番目が「別の候補を見る▶」 |

### 10-2. 抽選の重み `weight`
`"weight": { "base": 4, "mul": [ ["focus_love", 2.0], ["t_comm>=70", 1.5], ["region:C", 0.6] ] }`
（base は「1年あたりに候補になったときの相対的な出やすさ」。実際の発生率は §11 の統計表に合うよう調整）

### 10-3. 効果 `effects`
```json
"effects": {
  "stats":   { "health": -5, "stress": 3 },
  "subj":    { "eng": 4 },
  "skill":   { "music": 6 },
  "cash": -30,
  "debt": 0,
  "set":   ["smoker"],
  "clear": ["ex_smoker"],
  "counter": { "job_changes": 1 },
  "person":  { "add": "partner" },
  "schedule": [ { "event": "ev_r_quit_smoking", "inYears": [2, 6] } ],
  "stage": "ronin",
  "log": "🚬 タバコを吸うようになった"
}
```

### 10-4. 判定つき選択肢
```json
{ "label": "告白する",
  "roll": { "base": 0.45, "w": { "t_comm": 0.5, "looks": 0.3, "social": 0.2 } },
  "success": { "...": "..." },
  "fail":    { "...": "..." } }
```
`showRate: true` の選択肢は判定確率を「成功率◯%」として表示（入試・採用・資格試験・治療など）。恋愛など人の気持ちにかかわる判定は表示しない。

### 10-5. テキストの差し込み
`{year} {month} {age} {name} {pref} {partner} {spouse} {child} {school} {job} {club}`
絵文字は**文頭に1つ**を基本（ログを縦に流したときにアイコン列として揃う）。

## 12. 年齢と死の扱い（小学生向けの配慮）
- 死亡はゲーム終了。死因は「病気」「事故」「老衰」のいずれかで、テキストは穏やかに（描写しない）
- 35歳未満の死亡は統計的にまれ（年0.05%程度）なので補正しない。ただし難易度ハードでも上げない
- 終了時は必ずリザルト画面（人生のふり返り）へ
