## 1. 縦画面（スマホ）対応
- **縦長の画面では縦レイアウト、横長では今の横レイアウト**に自動で切りかえる（回転したらその場で切りかえ。ゲームは止めない）。「横向きにしてね」画面と `screen.orientation.lock('landscape')` は廃止。
- 縦レイアウトのステージは **横720 × 縦1280〜1600**（はばは固定、高さは画面に合わせてのばす）。のびた分はタイムラインを長くして使う。Galaxy Z Fold7 の外画面（細長い）でもすき間が出ない。内画面（ほぼ正方形）は横レイアウトで表示。
- 全画面を縦レイアウト版にする：タイトル／はじめから／誕生／メイン／選択肢ポップアップ／職業・学校の詳細／通知表／リザルト／これまでの人生／バックログ／オプション。
  - 選択肢ボタンは縦1列にならべる。2列・3列の表は列を減らし、入りきらない分は ◀▶ のページ送り（スクロールバーは使わない）。
  - もどる・とじるボタンは **縦画面ではすべて右上、横画面ではすべて今の位置** に統一。
- 文字の大きさは横画面と同じ（ステージごと拡大・縮小するしくみは今のまま）。

## 2. シンプルUI（新しいふつう）と、くわしいUI（今のUI）
オプションに「画面の表示：**シンプル**（はじめはこれ）／くわしい」を追加。くわしい＝今のUIそのまま。

### シンプルUIのメイン画面にのこすもの
| 場所 | 中身 |
|---|---|
| 上 | 年月・名前・年齢・速さボタン（一時停止／▶／×2／×4） |
| 顔の横 | 「いまの自分」1行：例「ITエンジニア・結婚している・子ども2人」（変わったときに光る） |
| ゲージ | **満足感・健康・ストレス** の3本だけ（高さ・はば・数字の位置をそろえる）。16歳からは所持金も1行 |
| まん中 | タイムライン（今のまま） |
| 下 | ［くわしく］［方針：〇〇］［バックログ］［オプション］の4つを同じ大きさで |

- 背景画像は顔の後ろにうすく敷く（縦画面ではとくに場所をとらないように）。
- ［くわしく］でポップアップ：本人ステータス・職業ステータス・状況／家族／通知表／お金のタブ（今の右側の中身）。ページはタブで切りかえ、スクロールなし。
- タイムラインの1件ごとの「＋3」などの数字の変化は、シンプルでは出さない（くわしいだけ）。

### ゲーム開始時のお知らせポップアップ（3枚）
誕生画面は「〇〇県に誕生した！」と顔・名前だけにしぼり、そのあと3枚を［つぎへ］で順に見せる。あとから［くわしく］→「生まれ」タブで見直せる。
1. **お父さん・お母さん**：年齢・仕事（会社員／パートなど）を1人1行。ひとり親のときはそれだけ。
2. **家庭**：きょうだい・同居の祖父母・家（持ち家／賃貸）・家のくらし向き（ゆとりがある／ふつう／きびしい の3段階でことばだけ）。
3. **都道府県の特徴**：地域・人口・大学進学率（全国とくらべる）・学校や会社の多さ＋**その県の特徴を2行**（例：「大学や会社が多く、選べる道が広い。家賃は高め」）。
   - 47県ぶんの2行テキストを `data/prefectures.json` に `feature` として足す（統計にもとづく内容だけ。名物などの観光情報は入れない）。

## 3. 採点の廃止 → 幸せレベルを自分で決める
- 「幸せのいちばんの基準」の質問を消す。はじめからの流れは **性別 → モード → 名前**。
- 0〜100点・5段階エンディング（幸福な人生など）は廃止。
- 人生の最期（死亡ポップアップ → 人生ムービーのあと）に
  「〇〇さんの人生。ふりかえってみて、幸せレベルは？」→ **★1〜5 をタップ**（★を押すと確認：「★4 でけってい？」）。
- リザルト・これまでの人生のカードは「点数／エンディング名」のかわりに **★の数** を出す。
- 満足感ゲージはゲームの中では今まで通り使う（イベントの判定に使っているため）。リザルトでは「満足感の平均」は参考として表示するだけ。
- 前のバージョンの「これまでの人生」の記録は、点数のまま表示する（消さない）。とちゅうのセーブは、そのまま続けられて最後に★を選ぶ。

## 4. 動くチュートリアル
- はじめての人生のとき、誕生のお知らせポップアップのあとに自動で始まる。オプションに「あそびかたをもう一度見る」、タイトルの最初の1回だけ［スキップ］。
- **本物のゲーム画面の上で**、説明する場所だけを明るくして（ほかを暗く）、ふきだしで説明。タップで次へ。説明中は時間が止まる。
  1. 人生は春夏秋冬で**自動で進む**。速さボタンと一時停止
  2. **タイムライン**に出来事が新しい順に出る
  3. **ゲージ**（満足感・健康・ストレス）
  4. **［くわしく］**で全部のステータスが見られる
  5. **方針**で、何をがんばるかを決められる
  6. （最初の選択肢イベントが来たとき）**選択肢**は自分で選ぶ。［相談する］［くわしく］の場所
  7. （最初の分岐点のとき）**人生の分岐点**はこのように大きく知らせる
  8. 最後に、人生の**幸せレベルは自分で決める**
- 6・7は「その場面が初めて来たとき」に出す（最初にまとめて見せない）。
- 説明の位置は画面の部品の位置から計算するので、縦・横どちらでも同じ文章で出る。

## 5. プレイ時間を短くする（ジャネーの法則）
目標：**等速で8〜10分**（今は15分前後）。投稿 約380 → **約220件**、選択肢 約80 → **約50回**。

1. **年をとるほど時間が速く流れる**：投稿1件あたりの表示時間（等速）
   | 年齢 | 今 | 新 |
   |---|---|---|
   | 0〜22歳 | 1.5秒 | 1.5秒 |
   | 23〜39歳 | 1.5秒 | 1.2秒 |
   | 40〜64歳 | 1.5秒 | 0.9秒 |
   | 65〜79歳 | 1.5秒 | 0.6秒 |
   | 80歳〜 | 1.5秒 | 0.4秒 |
2. **イベントの回数を年齢で減らす**
   - 選べるランダムイベントの出やすさ：23〜64歳 ×0.7、65歳〜 ×0.4
   - 流れるだけのイベント（日常・ヒントなど）は1年の上限：〜22歳 4件、23〜64歳 3件、65〜79歳 2件、80歳〜 1件
   - 65歳からは季節を「春・秋」の年2回、80歳からは「春」の年1回にまとめる（季節ボタンの表示もそれに合わせる）
   - 必須イベント・分岐点・家族の大きな出来事は減らさない
3. **ジャネーの法則をゲームの中で教える**：60歳になったとき1回だけ流れるイベント
   「最近、1年がとても早く感じる。年をとるほど、1年が人生にしめる割合が小さくなるかららしい（ジャネーの法則）」
4. `tools/sim.js` に「等速でのプレイ時間の見こみ」を出す（投稿×表示時間＋選択肢×6秒）。目標に入るまで数字を調整する。

## 6. 人生の分岐点ポップアップ
- 次のことが起きたら、時間を止めて**大きなポップアップ**を出す（タップでとじる）。
  - 進路：小・中・高・大学・専門などへの**入学**、**卒業**、浪人
  - 仕事：**就職**、**転職**、**昇進（課長以上）**、**失業**、**起業**、**定年退職**
  - 家族：**恋人ができた**、**結婚**、**離婚・再婚**、**子どもの誕生**
  - くらし：**県外への引っ越し**（上京など）、**家を買う**
  - 現実的モードのみ：大きな病気、家族との別れ
- ポップアップの中身：「人生の分岐点」の見出し・年齢・大きな1行（例「💍 あおいと結婚した！」）・1〜2行の説明・イベントCG（あれば。なければ背景画像）。
- 見つけ方：イベントごとに書きこむのではなく、**ステータス（在籍段階・仕事・結婚・子どもの数・住んでいる県など）が前と変わったとき**に自動で出す。イベントを足しても出し忘れがない。
- 選択肢を選んだ直後の「結果」ポップアップと重なるとき（プロポーズ成功など）は、結果ポップアップを分岐点の見た目にして、2回出さない。
- タイムラインでは分岐点の投稿を金色のわく＋少し大きい文字に。バックログに「分岐点」のジャンルを足す。
