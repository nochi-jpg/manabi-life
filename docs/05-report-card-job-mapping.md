# 通知表＆職業マッピング仕様

## 概要
プレイヤーが毎年受け取る「通知表」は、隠しステータス「細分化された学力」を可視化する唯一のツール。通知表の成績パターンが、後の職業選択肢の難易度を決定する。

---

## 1. 細分化された学力ステータス

### 1-1. 教科別学力パラメーター（隠し）

6つの教科ごとに、0～100の学力値を持つ：

| 教科 | 説明 | 影響職業 |
|------|------|--------|
| **国語** | 読み書き、文章力、表現力 | 先生、記者、作家、営業 |
| **算数/数学** | 計算、論理、代数 | エンジニア、会計士、医者、建築家 |
| **理科** | 物理、化学、生物、実験 | 科学者、医者、エンジニア、パイロット |
| **社会** | 歴史、地理、政治経済 | 公務員、歴史家、営業、経営者 |
| **英語** | リーディング、ライティング | グローバル企業、外交官、通訳、ツアーガイド |
| **体育** | 運動能力、健康管理 | スポーツ選手、体育教員、警察官、軍人 |

### 1-2. 教科別学力の計算式

```
教科別学力 = 基本値（隠し才能「学力」） + 3歳・6歳選択の傾向値 + イベント加算

例：
隠し才能「学力」= 70
6歳選択「計算する」 = 毎年+5傾向
毎年の算数学力増加 = 70 × 0.3 + 5 + ランダム
                = 21 + 5 + ランダム
                = 26～28/年

一方、英語は傾向加算がないため：
毎年の英語学力増加 = 70 × 0.3 + 0 + ランダム
                = 21 + ランダム
                = 19～23/年
```

### 1-3. 教科別学力の独立性

- 各教科は**完全に独立**して成長する
- 算数が得意でも、国語が苦手なままの場合がある
- 「得意教科と不得意教科の凹凸が大きい子」も存在

**教科**：国語、算数、生活、体育

┌─────────────────────┐
│  ★ 1年生 2学期 ★    │
│                     │
│ 国語：  〇           │
│ 算数：  ◎           │
│ 生活：  △           │

### 3-2. 職業選択時の難易度計算

```javascript
function calculateJobSelectDifficulty(jobId, reportCardData) {
  const job = jobs[jobId];
  const baseDifficulty = job.baseDifficulty;
  
  let subjectPenalty = 0;
  
  // 必要教科スコアとの比較
  for (const [subject, requiredScore] of Object.entries(job.requiredSubjects)) {
    const playerScore = reportCardData[subject];
    
    if (playerScore < requiredScore) {
      // スコアが足りないほど難易度UP
      const shortage = requiredScore - playerScore;
      subjectPenalty += shortage * 10;
    } else {
      // スコアが足りていれば難易度DOWN
      const surplus = playerScore - requiredScore;
      subjectPenalty -= surplus * 5;
    }
  }
  
  const finalDifficulty = baseDifficulty + subjectPenalty;
  return Math.max(50, Math.min(200, finalDifficulty));
}

// 使用例
const reportCard = {
  japanese: 3,
  math: 4,
  science: 2,
  society: 3,
  english: 1,
  pe: 5
};

const engineerDifficulty = calculateJobSelectDifficulty("engineer", reportCard);
// 必要：数学4, 理科3, 英語2
// プレイヤー：数学4(-5*4=-20), 理科2(+10*1=+10), 英語1(+10*1=+10)
// 難易度 = 100 + (-20) + 10 + 10 = 100

const doctorDifficulty = calculateJobSelectDifficulty("doctor", reportCard);
// 必要：数学5, 理科5, 英語4, 国語3
// プレイヤー：数学4(+10*1=+10), 理科2(+30*3=+30), 英語1(+30*3=+30), 国語3(0)
// 難易度 = 150 + 10 + 30 + 30 = 220 （上限200に制限）
// → 医者は目指しにくい
```

## 4. 進学先での教科選択への影響

### 4-1. 高校選択時

通知表の成績に基づいて、進学できる高校の「科」が限定される。

```
普通高（全教科選択可）
理系高（数学・理科が必須、スコア3以上推奨）
文系高（国語・社会が必須、スコア3以上推奨）
商業高（数学・社会が必須）

例：
数学1, 理科1の場合 → 理系高は難関。普通高か商業高を勧められる
```

### 4-2. 大学学部選択時

```
工学部：数学4, 理科4必須
医学部：数学5, 理科5, 英語4必須
文学部：国語4, 英語3推奨
商学部：数学3, 社会3推奨
国際学科：英語5, 社会3推奨
教育学部：全教科3推奨
```

## 5. 通知表のゲーム的な「楽しさ」

### 5-1. 進路ガイダンス

毎年の通知表に「進路指導コメント」が付く：

```
3年生 1学期
「数学が得意ですね。エンジニアや建築家、
または数学の先生も向いています」

「英語と理科が課題。今からでも伸ばす
工夫をしましょう」
```

→ プレイヤーが「あ、この職業を目指すなら、この教科を伸ばす必要があるんだ」と気付く

### 5-2. 隠しメッセージの根拠

通知表を見ることで、隠しステータスの推測が可能：

```
「4年連続、国語と社会が◎なのに、
英語と理科が△のままだ...。
自分は語学と科学系が苦手なんだな」

→ エンディング画面で確認：
英語才能 = 35, 理科才能 = 42（低い）
→ 「あ、そっか。生まれ持った才能だったんだ」
```

## 6. 実装時の注意点

### 6-1. 通知表の「見栄え」
- 毎回同じパターンだと飽きるため、季節や コメント内容でバリエーション
- 進路指導コメントは、そこまでの累積スコアから自動生成

### 6-2. 職業難易度のバランス
- 全職業がほぼ同じ難易度だと「選択肢がない」状態に
- プレイヤーの得意教科で「入りやすい職業」が必ず3～4個ある設計

### 6-3. 通知表の「正当性」
- ランダム要素が大きすぎて、通知表がぶれぶれだと信用されない
- 教科別学力が毎年 +20～30 程度でゆっくり成長 → 通知表も段階的に変わる設計

### 6-4. 進学試験と通知表の連携
- 通知表スコア ≈ 進学試験の合否判定
- 「得意教科でも不合格」「不得意教科でも合格」というランダム性を保つ
