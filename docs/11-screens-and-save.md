# 11 画面の流れとセーブ

## セーブ（オートセーブ・やり直しなし）
- **人生は一度きり**。四半期（春夏秋冬）が進むたび、選択肢を選ぶたびに自動でセーブする。手動セーブ・ロードはない。
- 生きている人生が1つある間は、タイトルの一番上のボタンは **「つづきから」**（名前と年齢を表示）。「はじめから」は出さない。
- 人生が終わる（死亡）とリザルトを「これまでの人生」に保存し、セーブを消す。次にタイトルに戻ると **「はじめから」** に変わる。
- セーブはブラウザの localStorage。消えたときのために、「これまでの人生」はQRコード／テキストで書き出せるようにする（manabi-battle と同じ方式）。
- 選択肢のポップアップが出ている途中でブラウザを閉じた場合は、その選択肢の画面から再開（選び直しはできるが、乱数はセーブ時点で固定しておき、同じ選択なら同じ結果になる）。

## 画面
| 画面 | ファイル | 内容 |
|---|---|---|
| タイトル | `ui/title.html` | 白背景・ロゴ画像。ボタンは「はじめから（つづきから）」「これまでの人生」「オプション」だけ。`#continue` でつづきから表示 |
| 性別・名前 | `ui/start.html` | ①男の子／女の子を選ぶ ②苗字・名前を別々にランダム表示（🔀でシャッフル、✏️自分で決める）。`#name`・`#self` で②の表示 |
| 誕生 | `ui/birth.html` | 2010年4月。都道府県のルーレット → 「〇〇県に誕生した！」。名前・性別・家族・県のデータ →「人生をはじめる」。`#done` で止まった状態 |
| 職業の詳細 | `ui/job.html` | 就職・転職の候補をタップすると必ず出る。職場の画像・年収・手取り・賞与・負荷・福利厚生・ステータスの変化・必要資格・AIの影響・合格率（`data/job_display.json`） |
| メイン | `ui/mock.html` | タイムライン・ステータス・背景。`#adult` で社会人の表示。季節が進むと所持金の横に「＋62」「💰+124（賞与つき）」「−12」が小さく出て消える |
| 通知表 | `ui/report.html` | 毎年3月。紙の通知表（小は◎〇△、中高は1〜5）＋先生のことば（才能のヒント）＋来年度の重点方針を選ぶ |
| リザルト | `ui/result.html` | 人生のまとめ・才能の公開・お金のグラフ（マイナスの時期を赤で表示）・できごとを、4つのタブで切りかえ（スクロールなし） |
| これまでの人生 | （未作成） | リザルトの一覧。名前・生まれた県・年数・エンディング・点数のカードを並べ、タップでリザルトを開く |

## エンディングの点数
`docs/00-overview.md` の5段階（困難・試行錯誤・波乱万丈・バランス・幸福）を使う。点数は「満足感の生涯平均」を中心に、家族・健康・お金の余裕を加える（00 の旧式「学歴＋仕事＋家庭＋資産」より、生まれた環境で差がつきにくい）。
