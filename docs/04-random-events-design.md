# ランダムイベント設計仕様

## 概要
ゲーム中、毎年複数のランダムイベントが発生する。各イベントの**発生確率**と**成功判定**は、隠しステータス（才能）に基づいて決定される。プレイヤーはイベント結果から間接的に自分の才能を推測できる。

---

## 1. イベント発生メカニズム

### 1-1. 毎年のイベント生成フロー

```
年開始
  ↓
その年の年代（6～15歳、16～22歳など）に応じて
「発生可能なイベント」プールを決定
  ↓
各イベントの「発生確率」を才能ステータスに基づいて計算
  ↓
ランダム判定で、今年のイベントを1～3つ決定
  ↓
各イベントについて「成功/失敗」を判定
  ↓
結果テキストと パラメーター更新を実行
```

### 1-2. イベント発生確率の計算式

```
イベント発生確率 = 基本確率 × (関連才能 / 80) + 年代補正 ± ランダム

例：学力イベント「進学試験」
基本確率：30%（すべての子に起こり得る）
関連才能：学力 = 70
年代補正：高校受験期 = +5%
ランダム：±3%

最終確率 = 30 × (70/80) + 5 ± 3
        = 30 × 0.875 + 5 ± 3
        = 26.25 + 5 ± 3
        = 28～34%
```

**解釈**：
- 学力が低い（50）なら：確率 = 18～24%（起きにくい）
- 学力が高い（100）なら：確率 = 37～43%（起きやすい）

## 2. イベントカテゴリーと具体例

### 2-1. 学力系イベント（関連才能：学力）

#### イベント A：「進学試験」
**発生年代**：12歳（中学2年）、15歳（高校2年）、18歳（大学受験期）  
**発生確率**：基本30% × (学力/80) + 年代補正

**成功判定**：
```
成功確率 = (学力 / 100) × 難度係数 × 都道府県難易度 + ランダム
難度係数：難関高=0.6, 普通高=1.0, 高卒就職=1.2

例：難関高受験、学力80、東京（難易度0.85）
成功確率 = (80/100) × 0.6 × 0.85 + ランダム(-10～+10)
        = 0.408 + ランダム
        = 31～51%
```

**成功時テキスト**：
- 「◎〇△」「1～5段階」で好成績（内部ステータス学力+5）
- 「〇」「3」なら及第点（学力+2）

**失敗時テキスト**：
- 「△」「1～2」で不振（学力+1、モチベーション低下）
- 「進学を断念して就職へ」（進路変更）

**ヒントメッセージ**：
- 成功時：「得意な教科（国語・算数など）で高点をとった」
- 失敗時：「得意な教科でも点が取りにくい」

---

### 2-2. コミュ力系イベント（関連才能：コミュ力）

#### イベント B：「恋愛イベント」
**発生年代**：16～35歳  
**発生確率**：基本25% × (コミュ力/80) + 年代補正(20代高め)

**成功判定**：
```
恋愛相手が見つかる確率 = (コミュ力 / 100) × 環境補正
環境補正：都市部=1.2, 地方=0.8

例：コミュ力60、地方生まれ
確率 = (60/100) × 0.8 = 48%
```

**成功時テキスト**（テキストベース）：
- 「職場で素敵な人と出会いました」
- 「友達の紹介で恋人ができました」
- 「SNSで知り合った人と付き合うようになった」

**失敗時テキスト**：
- 「出会いがない」（イベント発生なし）
- 「誰かに好意を持たれたが、気づかなかった」（コミュ力が低い場合）

**ヒントメッセージ**：
- 「クラスメイトが『一緒に遊ぼう』と声をかけてくる」（コミュ力高い）
- 「周囲からの誘いが少ない」（コミュ力低い）

---

### 2-3. 芸術系イベント（関連才能：芸術センス）

#### イベント C：「創作イベント」
**発生年代**：全年代  
**発生確率**：基本15% × (芸術センス/80)

**成功判定**：
```
創作物が評価される確率 = (芸術センス / 100) × 職業適性

例：図画工作で作品を作る
芸術センス=85 → 90%が「好評」、10%が「普通」
芸術センス=30 → 30%が「いいね」、70%が「普通」
```

**成功時テキスト**：
- 「あなたの絵が先生に褒められた」
- 「図画工作で賞をもらった」
- 「友達があなたの絵を欲しがる」

**失敗時テキスト**：
- 「努力したが、期待されるほどの評価ではなかった」
- 「得意なはずなのに、うまくいかない日もある」

**ヒントメッセージ**：
- 「絵が上手だと先生に褒められた」（才能高い）
- 「頑張ってるが成果が見えない」（才能低いが努力中）

---

### 2-4. 運動系イベント（関連才能：運動能力）

#### イベント D：「運動会・スポーツイベント」
**発生年代**：6～20歳（集中）、その後は稀  
**発生確率**：基本40% × (運動能力/80)

**成功判定**：
```
選手選抜 = (運動能力 / 100)
90以上 → 代表選手に選ばれる
70～89 → 通常参加
50～69 → 参加
30～49 → 見学のみ
```

**成功時テキスト**：
- 「小学校の体育で1番速く走った」
- 「運動会で金メダルを取った」
- 「スポーツのコーチに『才能がある』と言われた」

**失敗時テキスト**：
- 「体育の授業が苦手」
- 「リレーで緊張してしまった」

---

### 2-5. 健康系イベント（関連才能：健康値）

#### イベント E：「病気・事故」
**発生年代**：全年代  
**発生確率**：基本15% × ((100-健康値)/80) ← 健康値が低いほど発生しやすい

**成功判定**（ここでいう「成功」＝回復）：
```
病気の回復速度 = 健康値 / 100
健康値=80 → 2～3年で回復
健康値=50 → 4～5年で回復、後遺症リスク
健康値=20 → 5年以上、重篤化リスク
```

**発生時テキスト**：
- 「すぐに風邪をひく」
- 「インフルエンザで寝込んだ」
- 「怪我をしてしまった」
- 「親が病気になった」（介護費用増加）

**治療イベント**：
- 「病院で治療」（医療費-20～50万）
- 「様子を見る」（長期化のリスク、給料減少）
- 「民間療法を試す」（ランダム：成功or失敗）

## 3. ヒントメッセージシステム

### 3-1. メッセージのトリガー

```
【学力イベント発生時】
才能＞80 → 「得意な教科で高点をとった」
才能50～80 → 「得意な教科と苦手な教科がある」
才能＜50 → 「どの教科も得意ではない」

【コミュ力イベント発生時】
才能＞85 → 「クラスメイトが『一緒に遊ぼう』と声をかけてくる」
才能70～85 → 「友達がいる。でも輪の中心ではない」
才能＜70 → 「周囲からの誘いが少ない」
```

### 3-2. メッセージの蓄積

- プレイヤーがゲーム終盤に達するにつれ、隠しステータスの傾向が見えてくる
- 「成功と失敗の傾向から、自分の才能が推測される」という状況を作る
- エンディング画面で初めて「あ、これだったのか」と気付く

## 4. イベント発生パターン（年代別）

### 4-1. 6～15歳（学生期前期）
- 学力系：進学、成績、教科得意不得意
- コミュ力系：友達関係、いじめ、誘い
- 運動系：運動会、スポーツ選抜
- 芸術系：図画工作、音楽発表
- 健康系：病気、怪我、親の病気

### 4-2. 16～22歳（学生期後期）
- 学力系：高校進学、大学受験、学部選択
- コミュ力系：恋愛（初）、友達づくり
- 芸術系：部活、文化祭
- 健康系：受験ストレス
- 運動系：部活（スポーツ系）

### 4-3. 23～40歳（仕事・結婚期）
- コミュ力系：恋愛（発展）、結婚
- 学力系：昇進試験、転職資格
- 芸術系：仕事での創造性
- 健康系：ストレス、過労
- 運動系：スポーツ活動（趣味）

### 4-4. 41～60歳（キャリア充実期）
- 学力系：昇進、管理職
- コミュ力系：人間関係、親の介護
- 健康系：加齢性疾患（50代以降）
- 運動系：定年後の健康維持

### 4-5. 61～80歳（人生終盤）
- 健康系：重篤な病気、介護
- コミュ力系：孫との関係、地域交流
- 運動系：寝たきりリスク

## 5. 実装時の注意点

### 5-1. イベント重複回避
- 同じ年に同じイベント（例：進学試験×2）が発生しない仕組み
- イベント発生後、クールタイムを設定（最短3年後など）

### 5-2. メッセージのバリエーション
- 同じイベントでも、成功/失敗、才能レベルで異なるメッセージ
- 計20～30パターン/イベント用意

### 5-3. ヒントメッセージの見つけやすさ
- プレイヤーがメッセージを見落とさないよう、色付けやハイライト
- 後から「メッセージ履歴」で確認できる仕組み

### 5-4. 確率の感じ方
- プレイヤーが「運の悪さ」を感じる一方で、実は「隠しステータス」が理由
- この「気付き」がエンディング画面での「ああ、そっか」感に繋がる
