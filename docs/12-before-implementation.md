- 妊活・妊娠・不妊治療（Kids・effects.js）：「子どもがほしい」で妊活中（wants_children）。毎年4月に、女性の年齢に合った確率で妊娠（pregnant）→3季節後（約10か月）に出産。流産はなし。妊娠しにくい夫婦の割合は妊活を始めた年齢で決まる（Menken 1986：25〜29歳9%・30〜34歳15%・35〜39歳30%・40〜44歳64%）。3年妊娠しなければ「不妊治療をする？」（ev_m_fertility_ask）。配偶者が強く望んでいれば A（する）とC（しない・配偶者の関係−25）、そうでなければ B（する・関係−6・生まれた子との関係の初期値が低い）とD（あきらめる）。治療中（fertility_tx）は年齢に合った確率で妊娠、お酒・タバコはやめる、費用は年30万円（43歳から保険が使えず150万円）、2年ごとに続けるか（ev_m_fertility_continue・同じ組み合わせ）。あきらめたら（gave_up_children）もう子どものことは聞かない。2人目・3人目でも同じ。別れた・別居・配偶者が亡くなったら妊活と治療は終わり（Kids.guard）。妊娠中の日常・出産の準備、治療中の日常・仕事との両立のイベント。状況の「その他」に 妊活中／妊娠中（男性は「◯◯が妊娠中」）／不妊治療中。選択肢の「見出し｜説明」は2行で表示。
